1. 일지기록

1.1 이모지와 특수문자 삽입기능

- 일지를 작성할때 또는 다른곳에서 사용할 때 
- 이모지와 특수문자를 기록하는 테이블을 만들자
```
CREATE TABLE assets (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    atype       TEXT NOT NULL,                      -- 자산 타입 (EMOJI, PHRASE, TEMPLATE, SYMBOL)
    name        TEXT NOT NULL,                      -- 자산 이름 / 이름표
    value       TEXT NOT NULL,                      -- 실제 데이터 본문 (마크다운, 기호, 텍스트 등)
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at  DATETIME DEFAULT CURRENT_TIMESTAMP,

    -- 약속된 키워드 외의 텍스트가 들어오는 것을 방지
    CONSTRAINT chk_atype CHECK (atype IN ('EMOJI',  'SYMBOL'))
);
```
- 위 sql은 sql용인데 pcms는 postgres임으로 변경필요

- 이모지넣기/특수문자 넣기 기능 추가.
    1. 툴바에 이모지 icon, 특수문자 icon넣기
    2. 클릭시 팝업으로 이모지, 특수문자 리스트가 뜨고 마우스 또는 화살표키로 선택, 선택된 것이 editor에 들어감.
    3. ctrl+1,2 -> 이미지, 특수문자에 연결되어 편집시 바로 그 위치에 팝업이 뜨고 선택하여 삽입가능

1.2 글자색상/배경색상 변경기능

- 현재 글자색상 변경하는 아이콘이 툴바에 있는데 그것을 aman과 같은 식으로 표현(aman을 참조 DocUserMain과 compoments)
- 배경색상 icon을 툴바에 새로 생성.(ui는 aman과 동일 또는 유사하게)

1.3 링크 기능 넣기
